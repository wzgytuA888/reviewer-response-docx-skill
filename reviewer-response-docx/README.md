# Reviewer Response DOCX Skill

A reusable Codex skill for evidence-based scientific manuscript revision and point-by-point Word response packages.

It reproduces reviewer comments in blue, writes responses in black, presents verified revised excerpts in red italics, maps completion claims to manuscript locations, preserves reviewer isolation, and keeps incomplete items visibly pending.

Copy `reviewer-response-docx` into the Codex skills directory, then invoke: `Use $reviewer-response-docx to process these reviewer comments and revise the supplied manuscript.`

This repository contains no manuscript, reviewer report, author identity, or unpublished study data.
