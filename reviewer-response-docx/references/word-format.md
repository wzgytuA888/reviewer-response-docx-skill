# Word response format

## Page and typography

- A4 page, 21.0 × 29.7 cm.
- Margins: top and bottom 2.54 cm; left and right 3.175 cm.
- Body: Calibri 12 pt, line spacing 1.1, 6 pt after, unless a supplied journal or prior-round template overrides it.
- Preserve source headers, footers, section breaks, and table styles when editing an existing response.

## Color and emphasis

| Element | Format |
|---|---|
| Reviewer headings and verbatim comments | `#255CDB` blue; heading may be bold; body regular |
| `Response` label | black, bold |
| Response prose | black, regular |
| `Revision` label | `#C00000` red, bold |
| Location line | black, bold |
| Revised manuscript excerpt | `#C00000` red, italic |
| Pending author note | `#C00000` red with a bold label |

Do not color unchanged quoted manuscript text red. Use plain italics for unchanged context and explain that convention in the preamble.

## Opening and location rules

Open with `Response to Reviewers`, manuscript reference, title, any incomplete-package warning, and a short note explaining colors and locations. Put editor instructions before reviewer sections.

Determine pages from the final clean Word file. Add section and accepted-view body paragraph number. Recheck locations after every manuscript edit. Never invent line numbers. For a figure, table, caption, or supplement, give its exact label and file.

## Marked and tracked files

The marked manuscript shows current-round changes in `#C00000` red. The tracked manuscript contains native Word insertions and deletions with a named author. Its accepted view equals the clean manuscript. Clean and marked versions differ visually only; accepted text, equations, tables, figures, headers, and references agree. Preserve original figure media unless a completed reviewer action explicitly replaces a figure with a verified file.

## Tables and isolation

Use visible grid tables, repeat header rows, prevent row splitting where practical, and keep evidence text concise. Create a standalone response per reviewer by default. It must not contain another reviewer's number, comment, recommendation, identity, or response.
